# MDR Platform 2.0.0 — change summary

- Base: MDR Platform 1.1.0 source archive.
- Android version: `2.0.0`, `versionCode 6`.
- Added two standalone assets: `mdr-studio-core.js`, `mdr-studio-runtime.js`.
- Added four scene-core tests; total Node tests: 17.
- Preserved the original engine, factory, ZIP guard, WebView host and generated Android templates.
- Added scene editing for primitive objects, selection, simple transforms, save/load and JSON import/export.
- Did not add GLTF import, skeletal animation, full physics, isolated custom-code execution, or APK build output.
